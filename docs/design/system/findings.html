Sello design system

Findings

Where the built app uses a component against its own meaning, rebuilds a shared component by hand, or writes a value where a token exists. A reference of the app as it is.

Three kinds of finding: misuse (a component used against its meaning), copies (a shared component rebuilt by hand) and hard-coded values (colour first, because dynamic colours are coming).

Not a finding: the same situation shown differently because the place differs (a save that did not finish shown in a sheet, next to the failed button or as a note), wording, width or wrapping, and differences from older design references. Nothing here asks for a decision or a code change.
