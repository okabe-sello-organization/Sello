Sello design system

Findings

Places where the built app does one job in more than one way, grouped by theme. Each finding shows its variants with the code and screenshots, and a recommendation.

For each finding, pick the variant to keep everywhere, or "All are fine" / "Both are fine", or "Other" with a note saying what you want instead; the note is optional for the others.

Your answers stay in this browser only (localStorage, per finding ID), so you can stop and come back.

When you are done, press Copy answers and paste the text in the chat. Each line reads F01: A — note; unanswered ones read (no answer).
