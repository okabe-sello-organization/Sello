Feature

Backup

Respaldo and Tus datos: save a backup file, export to CSV or JSON, and restore a Sello or FinanceTracker backup after a preview.

Purpose

Lets a person save their whole history to a file they choose, export it as a readable CSV or JSON file, and replace everything on the phone with a backup (Sello's own, or one from FinanceTracker, translated) after seeing what changes. Saving, exporting and restoring run in process-wide sessions, so leaving the screen never cuts them short.

Entry points

  • Tus datos is the first block of Configuración, slotted in by navigation: app/src/main/java/com/software/sello/navigation/SettingsDestinations.kt:44.
  • Respaldo opens from Tus datos' "Ver qué contiene" link, or after a file is chosen with "Restaurar", or when "Restaurar" is pressed while a restore is already under way: app/src/main/java/com/software/sello/navigation/SettingsDestinations.kt:47, wired in app/src/main/java/com/software/sello/feature/backup/TusDatos.kt:70 and TusDatos.kt:78.
  • The Respaldo destination: ShellScreen titled "Respaldo" (backup_title), no entry dock, no past-month ribbon: app/src/main/java/com/software/sello/navigation/BackupDestinations.kt:26.
  • The restored-history slip (RestoredSlip) is also shown at start-up; see the Start-up page.

Controls

  • Respaldar / Crear: opens the "Antes de guardar" disclosure as a ConfirmSlip (destructive = false) holding the disclosure BulletList; its action "Elegir dónde guardar" sends BackupAction.Create, which opens the system save picker (TusDatos.kt:161, app/src/main/java/com/software/sello/feature/backup/BackupPickers.kt:18). Dismissing the picker does nothing and says nothing.
  • Restaurar: with no restore under way, opens the system file picker; a chosen file then opens Respaldo, where it is checked. With a restore under way it opens Respaldo directly (TusDatos.kt:78, BackupPickers.kt:39).
  • Ver qué contiene: opens Respaldo (TusDatos.kt:286).
  • Exportar a CSV o JSON: opens the export dialog (below).
  • Borrar todos los datos: opens Borrar datos.

Screen: Respaldo

Only the restore section has baselines, captured on their own in Cobalto light (FeatureComponentsScreenshotTest); the screen as a whole has none.

Layout

One scrolling Column with spacing.md gaps (app/src/main/java/com/software/sello/feature/backup/BackupScreen.kt:91). Top to bottom, when no restore is under way:

  1. BackupProblems: the failed-save or unfinished-save ErrorSlip (BackupScreen.kt:107).
  2. Último respaldo: an unpinned Slip with a headlineSmall heading and, after a save, a landing "Guardado" Stamp (StampInk.Good); then LeaderLines for Fecha, Categorías, Gastos, Ingresos (and Metas, Pagos e ingresos fijos, Inversiones when there are any), Archivo size, and the file name in bodySmall (BackupScreen.kt:133).
  3. Antes de guardar: an unpinned Slip with the disclosure BulletList (BackupScreen.kt:211).
  4. A full-width filled SelloButton "Crear respaldo" / "Crear otro respaldo" and the caption "Luego eliges dónde guardarlo." (BackupScreen.kt:110).
  5. The restore section (below) last.

Once a file is being previewed, refused, replaced or answered, the restore section moves to the top and the screen scrolls there (instantly with reduced motion) (BackupScreen.kt:86, BackupScreen.kt:105). Once the history is replaced, the restore section is the only thing on the screen (BackupScreen.kt:106).

Legacy import (FinanceTracker)

When the chosen file is a FinanceTracker backup, the preview adds LegacyReportSection (app/src/main/java/com/software/sello/presentation/restore/LegacyReport.kt:29): a titleMedium heading "Desde FinanceTracker", then either "Sello pudo traer todo lo que tiene el archivo." or bullets under "Ajustado para que encaje en Sello:" and "No se importa:" (one line per kind of record and reason, e.g. "3 gastos: monto fuera de rango"), closing with "Por eso los totales de Sello pueden no coincidir con los de FinanceTracker." No baseline.

Controls

  • Crear respaldo: BackupAction.Create → save picker → the session saves (BackupViewModel.kt:83).
  • Elegir archivo / Elegir otro archivo: RestoreAction.Choose → file picker → RestoreAction.Chosen → checking (RestoreViewModel.kt:55).
  • Reemplazar con el respaldo: Confirm; Cancelar: Cancel; Volver: Dismiss; Comprobar: Check (reads the receipt again, never replaces); Aplicar …: ApplyPreferences; Ir al recibo: Leave, which finishes the session and restarts the app (RestoreViewModel.kt:78).
  • Back (arrow or system): pops, unless the history is or may be replaced, when it sends Leave (app/src/main/java/com/software/sello/navigation/BackupDestinations.kt:36, BackupScreen.kt:55).
