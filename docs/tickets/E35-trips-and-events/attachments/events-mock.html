Viajes y eventos: what a trip or an occasion cost

An expense can belong to one event: a trip, a wedding, Christmas. The event is only a tag with a name and an icon (owner, 2026-11-06): no budget and no dates. It never changes a category, a limit or a month's figures. Yellow outlines mark what is new on an existing screen.

Notes

  • Anotar varios gets the same row once for the whole receipt: every line goes to that event. An expense recorded by a fixed payment has no event unless the person adds one while correcting it.
  • Storage (SELLO-198): an events table and a nullable event on each expense. Room migration, exported schema, backup format v8 (older backups read as having no events), and the CSV/JSON export gains an event column.
  • The page's dates come from its expenses (first to last); an event with no expenses shows Sin gastos and a 0 total, never a failure.
  • Shares are of the event's own total, rounded half up to whole percents; the four shown add to 100 % here, but rounding may not always.
