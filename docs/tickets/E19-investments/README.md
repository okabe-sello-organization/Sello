# SELLO-E19 — Inversiones, and the 0.2.0 release

- **Status:** Done
- **Increment:** Post-MVP
- **Goal:** Let a person record investments in COP or USD with contributions, withdrawals, dividends and values, and see the portfolio and each investment's simple return.
- **Exit:** Inversiones is a tab with the v2 overview and detail; USD uses one dated app-wide rate; backups carry investments.

## Decisions

**Owner direction (2026-10-23):** decisions in [ADR 0017](../../decisions/0017-goals-recurrence-investments.md): simple return since the first
contribution, COP and USD with one app-wide manual rate, USD returns in USD, values show
their date and are never stale, dividends count in the gain, corrections with undo; no
network. The last ticket releases E17, E18 and E19 as one `0.2.0`.

**Owner decision (2026-10-29):** SELLO-113, the `0.2.0` release, is dropped and its
file removed. The epic is done with SELLO-105 to SELLO-112; nothing is released or tagged.
