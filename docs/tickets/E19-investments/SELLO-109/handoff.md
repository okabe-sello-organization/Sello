# SELLO-109 — Add the Inversiones tab overview

Inversiones is the fourth tab (`InversionesDestination`, `InversionesScreen`, `InvestmentsRenderModel`): the value with Gana / Pierde in ink, the signed return, the breakdown, the valuation dates and the rate used, then the bar and rows largest first; states never show zero.
Design-system extensions: `AnswerSlip(lossAmount)`, `PerformanceLine(even)` without tabular figures, `SplitBar(gap)`, repeating shades, the dashed no-value row.
Open: title styles still give commas a digit's width app-wide (the catalog shows it); only Inversiones' own texts avoid it.
