# SELLO-111 — Set the USD rate

Dólar (`UsdRateScreen`) shows the current rate and the earlier ones; Cambiar la tasa (`UsdRateEntryScreen`) records a new dated rate typed with the pad's comma (`DecimalDraft`, `AmountKeypad(onComma)`), 1,00–100.000,00.
It is reached from Configuración's Dólar row; the overview's rate line opens it once the tab is in the bar (SELLO-110).
Open: a mistaken rate is replaced by entering another, never deleted (rule 11).
