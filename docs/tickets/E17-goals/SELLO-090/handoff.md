# SELLO-090 — Create, edit and delete goals

Nueva meta and Editar meta (`GoalEditorRoute`, `feature/goals/GoalEditor*`) create, edit and delete goals with the Sello pad (`SlidingKeypad`), the icon circle (`GoalIconCircle`), Para cuándo and the plan with projected months (`GoalPolicy.pace`, `GoalPolicy.withTarget` for edits). Metas' **+** and **Crear una meta** and the goal's edit pencil open it.
Still open: Aportar / Retirar (SELLO-091) turns on Metas' green dock and Retirar dinero; **Marcar como lograda** in the edit form and the celebrations of a target change are SELLO-092's; catalog examples for `GoalIconCircle` and `SlidingKeypad` are SELLO-094's.
