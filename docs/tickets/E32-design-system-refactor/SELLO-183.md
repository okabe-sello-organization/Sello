# SELLO-183 — The design system has the tokens the app writes by hand

- **Type:** Task
- **Priority:** P1
- **Status:** Backlog
- **Depends on:** None
- **Gate:** G2

### Outcome
`:design-system` offers the type styles, alpha values, corner shapes, icon button and
signed-amount text that screens now write by hand, so later tickets can use them.

### Acceptance criteria
- Type styles for the weights and sizes the app repeats (H17–H49), alpha tokens (at least
  disabled 0.38 and scrim 0.55), shape tokens for the repeated corners (H50–H58), a shared
  icon button and a public signed-amount text (C21, C22).
- The foundations and components pages describe them. No screen changes yet; every
  baseline is unchanged.
