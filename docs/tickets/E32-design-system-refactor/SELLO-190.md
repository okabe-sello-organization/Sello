# SELLO-190 — Every colour comes from the theme

- **Type:** Task
- **Priority:** P1
- **Status:** Backlog
- **Depends on:** SELLO-189
- **Gate:** G2

### Outcome
No screen or resource draws a colour that the theme does not give it, so a later
dynamic-colour scheme can reach every part.

### Acceptance criteria
- H01–H16 are fixed: no visible Color.White or fixed scrim, no palette read outside the
  theme, role literals reference the role they copy, the window backgrounds follow the
  theme.
- Every baseline is unchanged, or each change is explained.
- The foundations page's dynamic-colours box is updated.
